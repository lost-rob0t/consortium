* Decision

APPROVE the contract-first bootstrap only.

The approved implementation slice is limited to:

- repository mission and agent contracts;
- deterministic ADARD phase/failure-routing facts;
- a durable run/artifact schema;
- fresh-context and authority invariants;
- explicit RAGE-as-tool policy;
- regression tests for deterministic state semantics.

* Conditions

1. This decision does not approve an LLM provider adapter.
2. This decision does not approve autonomous RAGE recursion.
3. This decision does not approve unrestricted tools/effects.
4. Future development admission must be executable rather than documentation-only.
5. Provider adapters must prove fresh session/context identity.
6. Verifier-owned failure classification and immutable artifact storage remain required follow-ups.
7. Runtime test results must not be claimed unless executed.

* Routing

Proceed to bounded bootstrap development. After implementation, run an independent exact-head verification. If SWI-Prolog is unavailable in the verification environment, record runtime verification as blocked rather than treating static inspection as a pass.
