* Decision

=READY_FOR_REALIZATION=

Promote the architecture in =CONSORTIUM-DESIGN-001= as the design basis for the first Consortium implementation.

The selected architecture is:

#+begin_example
fresh-root ADARD artifact DAG
  + Prolog-RLM execution substrate
  + immutable runtime artifacts
  + bounded evidence/context manifests
  + independent adversarial review
  + deterministic eligibility/promotion gates
  + attempt fencing and cancellation
  + canonical Org promotion separate from hot runtime state
#+end_example

The transcript-orchestrated architecture is rejected.

An external-agent/filesystem architecture is not canonical, but may later be implemented as an adapter capable of satisfying the same ADARD protocol.

* Conditions Before Implementation Is Accepted

1. Prove actual fresh-root/provider-history isolation with an instrumented deterministic test.
2. Use a stable/public Prolog-RLM integration surface rather than internal predicates.
3. Resolve direct-link licensing/distribution intent for Prolog-RLM, or use a process/tool boundary until resolved.
4. Implement the DESIGN-001 acceptance criteria TDD-first.
5. Keep client-visible operations asynchronous and cancellation-safe.
6. Do not enable RAGE until whole-tree cycle/fingerprint/budget controls have deterministic tests.
7. Do not claim realization/verification success from this research run; no implementation tests were executed.

* RAGE Decision

RAGE is explicitly deferred.

The first implementation target is one ADARD run only. RAGE will later compose ADARD runs under a separate bounded escalation policy.

* Next Run

The next ADARD run should research and design the executable bootstrap against the current Prolog-RLM public interfaces, then realize it TDD-first only after that run passes adversarial review and decision.

This decision does not authorize silent changes to Prolog-RLM itself.
